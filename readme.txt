Fahar Theme Child is a presentation foundation for a modern portfolio experience built on the Hello Elementor parent theme.

== Description ==

This child theme provides modular WordPress setup, RTL-first design tokens, defensive Elementor integration, conditional assets, and semantic portfolio template scaffolding. It intentionally does not implement the final portfolio product or require Elementor Pro.

== Installation ==

1. Install the Hello Elementor parent theme.
2. Upload Fahar Theme Child to the WordPress themes directory.
3. Activate Fahar Theme Child from Appearance > Themes.
